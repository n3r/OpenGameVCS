# Unicode 15.0 repertoire authority

`DerivedAge-15.0.0.txt` is the Unicode Character Database `Age` property file
from Unicode 15.0.0, published at
<https://www.unicode.org/Public/15.0.0/ucd/DerivedAge.txt>. Its SHA-256 is
`7570877e0fa197c45338f7c41a02636da4e14c8dba6a3611a01cd30bf329d5ca`.

OpenGameVCS format v1 uses the assigned scalar ranges in that file as its
frozen text repertoire. Surrogate code points are excluded even though the
Unicode data file assigns them an `Age` value. The generated compact interval
table is a mechanically derived execution aid; this versioned source file is
the authority.
