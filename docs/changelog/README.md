# PRD changelog

Each completed PRD has one durable, human-readable delivery record in this directory. Entries describe public artifacts, compatibility decisions, important review remediation, acceptance evidence, operational impact, and rollback boundaries. The PRD remains the source of requirements and links back to its corresponding changelog entry.
